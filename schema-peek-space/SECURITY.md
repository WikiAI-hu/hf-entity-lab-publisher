# Security reporting

For suspected security or privacy issues, contact the project via [the official product page and privacy notice](https://www.wikiai.hu/wikiai-schema-peek/#privacy-policy). Do not post secrets, personal data or raw reports from private pages in public issues. Include version, browser, a minimal reproducible example with synthetic data, and observed behavior.

The GitHub package is intended for local developer testing. See [LICENSE.md](LICENSE.md) for the adopted use terms and [README.md](README.md) for installation instructions and Chrome Web Store status.
