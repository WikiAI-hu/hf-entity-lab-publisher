# Professional collaboration / Szakmai együttműködés

WikiAI Schema Peek welcomes cooperation with developers, technical SEO and AI visibility specialists, researchers, accessibility and security professionals. It is a source-available freeware project with reserved rights, not an open-source project. The [license 1.0](LICENSE.md) was adopted on 26 November 2026. No unapproved modification or redistribution of protected original code is authorized by this guide.

## How to collaborate

1. Once the project is public, report reproducible bugs or propose features through GitHub Issues if enabled, or contact the project via the [official product page](https://www.wikiai.hu/wikiai-schema-peek/). Provide version, expected behavior, observed behavior and a synthetic example where possible.
2. Contact the project owner before preparing or submitting code modifications. Please do not open unsolicited code pull requests; the project uses an approval-first development process.
3. If a collaboration is accepted, agree separately in writing on the technical scope, permissions to modify or access the code, the treatment and license of contributions, rights to incorporate and distribute the work in official releases, credit, review, and any compensation or confidentiality requirements. The agreement may supersede the default inbound licensing rule under GitHub's applicable terms.
4. Work in the approved development branch or private collaboration space, submit changes for review, provide reproducible tests, and obtain explicit maintainer approval before inclusion in an official release. The project owner controls official versioning and distribution; collaboration does not itself grant permission to issue independent versions.

Do not submit material you do not have permission to contribute. Do not include secrets, client data, private page content or personal data in public issues or code. See [SECURITY.md](SECURITY.md) for private security reporting. Separately licensed Schema.org-derived material retains its own rights; this guide does not restrict them or mandatory legal exceptions.

## Magyarul

Nyitottak vagyunk webfejlesztők, technikai SEO- és AI-láthatósági szakemberek, kutatók, akadálymentességi és biztonsági szakértők közreműködésére. A WikiAI Schema Peek jogfenntartásos, megtekinthető forráskódú, ingyenesen használható szoftver, nem nyílt forráskódú projekt. A [licenc](LICENSE.md) 1.0 változatát 2026. november 26-án fogadta el a projektgazda.

1. Nyilvános kiadás után a hibajelentések és fejlesztési javaslatok az Issues felületen (ha engedélyezett), vagy a [hivatalos termékoldal](https://www.wikiai.hu/wikiai-schema-peek/) kapcsolati útján küldhetők be. Add meg a verziót, az elvárt és a tapasztalt működést, lehetőleg mesterséges tesztpéldával.
2. Kódmódosítás előkészítése vagy beküldése előtt kérj külön engedélyt. Előzetes egyeztetés nélküli kódos pull requestet ne küldj.
3. Elfogadott együttműködés esetén írásban tisztázzuk a műszaki feladatot, a hozzáférési és módosítási jogokat, a hozzájárulás licencét, hivatalos kiadásokban történő felhasználását, a névfeltüntetést, az ellenőrzést és az esetleges díjazást vagy titoktartást. A külön megállapodás felülírhatja a GitHub általános hozzájárulási licencszabályát.
4. Jóváhagyott fejlesztői ágon vagy privát együttműködési térben dolgozunk. A módosításokat tesztekkel együtt vizsgáljuk felül. A hivatalos kiadás a projektgazda kifejezett jóváhagyásával történik; az együttműködés önmagában nem jogosít saját kiadásra.

Csak olyan hozzájárulást küldj, amelyhez megvannak a szükséges jogaid. Nyilvánosan ne ossz meg titkot, ügyféladatot, privát oldaltartalmat vagy személyes adatot. Biztonsági problémákhoz lásd: [SECURITY.md](SECURITY.md). A Schema.org-eredetű anyag külön licence és a kötelező jogi kivételek változatlanul alkalmazandók.
